# Connectly

A full-stack social media application inspired by Instagram and Threads.

## Features

- JWT Authentication
- Create, Update and Delete Posts
- Image Uploads with ImageKit
- Like / Unlike Posts
- Comments System
- Follow / Unfollow Users
- User Profiles
- Followers & Following Lists
- Personalized Feed
- User Suggestions

## Tech Stack

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- ImageKit

Frontend (Coming Soon):
- React
- Tailwind CSS
- Framer Motion
- Axios
